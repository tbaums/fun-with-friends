# fun-with-friends brand assets

- **Clear space:** keep at least one mark-square of empty space around the mark or lockup.
- **Minimum size:** never render the mark below 16px or the wordmark below 90px wide.
- **One accent:** exactly one Ember `#e8a33d` square — never two, never a different hue.
- **Never recolour:** use the shipped variants; do not restyle the mark, wordmark, or palette.
- **Never add a tagline to the mark:** the mark and wordmark stand alone; taglines live only on the social card.
